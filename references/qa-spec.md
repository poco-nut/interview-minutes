# Q&A 规范

## 一、收录标准

**哪些内容进 Q&A，哪些进正文分节**：

- **正文分节**：受访人主动陈述的、成体系的公司信息（成立、团队、股权、技术、产品）
- **Q&A**：投资人主动提问引出的内容 —— 尤其是质疑、风险追问、竞品比较、敏感事项

**每条信息只出现一次**：以「介绍」形式出现的内容进正文节，以「问答」形式出现的进 Q&A，同一事实**不得两处都写**。判断依据是素材里它的呈现形式——投资人主动提问引出的内容（含追问、质疑、竞品比较、敏感事项，以及在被问时才说出的成体系事实）一律只写在 Q&A，正文节不得出现。

只有一句话、撑不起一段的问答，且属于主动陈述范畴的，可并入正文相应位置，不单列 Q 条；提问引出的仍归 Q&A。

## 二、编号与归属

格式：

```
Q1（提问机构·姓名）：问题文本？
答：
答案文本。
```

- 编号：`Q1` `Q2`…… 连续，不跳号，不用 `Q&A1`
- **归属按提问人的实际层级写**：
  - 多人多机构的访谈（卓然的四方机构）：`Q1（远见资本·安然）：` —— 机构 + 姓名
  - 有机构无姓名：`Q1（复星创富）：`
  - 路演多人提问，只有名字：`Q1（李浩）：`
  - 一对一访谈：`Q1：` 不带括号
- 归属里的机构名用**简称**（与正文一致），不加书名号

**不要把所有问题都归给复星**。素材里谁问的就写谁——卓然那份 12 条 Q 里只有 1 条是复星问的，其余归属远见资本、海岳资本。归属错了会让读者误判是谁的关注点。

## 三、问题文本的写法

转写稿里的原始提问通常是口语的、碎的、有重复的。改写成规范问题**遵循四条**：

1. **合并**：同一提问人围绕同一主题的连续追问，合成一个 Q
2. **保留子问题顺序**：一条 Q 里常带 3–5 个子问题（云驰半导体 Q2 问了四个），按原顺序保留，中间用问号断开
3. **去口语**：`那个` `就是说` `我想问一下` 全部删掉
4. **不改原意**：可以精简，不可以替提问人改换关注点

```
✗  Q2（孙悦）：那个我想问一下就是公司之前在是德做的是电的 WAT，然后现在要做光的 PIC OWT，这块 know-how 是怎么切换的？
✓  Q2（孙悦）：公司在是德科技做的是电的 WAT（服务中芯国际、华虹），现在要做光的 PIC OWT，know-how 如何切换？
```

长问题拆成若干短问句，比长定语从句可读。

## 四、答案的写法

- **`答：` 独立成行**（脚本会加粗），答案正文另起段落
- **按子问题顺序作答**：Q 里有几个问号，答案就分几段，顺序一一对应
- **子问题多时，每段用引导短语**（与正文规范一致）—— 样本的标准做法是 `关于XXX：`

```
Q2（方）：当前的硅光芯片是否需要 OWT 去测？国内硅光 Fab 进度比 Tower 等偏慢，公司研发设备基于哪些大厂？为什么预期 2028 年会有这方面销量？

答：
关于是否需要 OWT 测试：用在传统可插拔模块上的硅光芯片不需要晶圆级测试……
关于市场预期依据：判断依据有两方面。一方面目前市场上有很多硅光项目在立项……
关于客户与生态：台积电是 PIC、EIC 与封装三件事一家做……
```

- **先结论后依据**：首句直接给判断，后面补理由和数字
- **合并口径**：一条 Q 下多位受访人发言时，把各条口径按事实顺序并列陈述，**不加归属短语**（见 `writing-spec.md` 第二节），不要拆成多条 Q
- **答案长度**：多在 80–400 字。素材稀少就短，**不要为了篇幅注水**

## 五、拒答与敏感问题

如实记录，不删、不美化、不编理由：

> 关于江苏张某：该问题未获正面回应，受访方愿意线下再沟通；并说明公司在法律上切割得很干净，不会有任何问题。

> 关于智联科技：智联科技想做硅光晶圆级测试是肯定的，但并不像其宣传的那样已有方案。

**提问尖锐、受访人回避**——这本身就是尽调信号，写进去比删掉更有价值。

## 六、轻度核查在 Q&A 里的落法

Q&A 里出现的数字与头衔同样纳入核查范围，存疑处**在答案段内括注**，不改原话：

> 答：团队发表顶会顶刊论文 100 余篇（公开检索的该学者论文量为 80 余篇，此处以公司口径为准）。
