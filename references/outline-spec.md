# 骨架规范

骨架由**交集分析**得出：五份公司纪要样本里，四份新版式纪要（卓然聚变、远瞳科技、星阑科技、云驰半导体）出现的章节做了命中统计，**命中 4/4 的定必备，命中 1–3/4 的定备选**。

## 一、必备节（固定输出，不可省）

```
<公司简称>访谈纪要                     ← 标题
时间：/ 地点：/ 访谈人员：              ← 元信息块
<公司简称>项目简介                      ← 一段话总述
一、公司概况与定位
二、创始团队
三、股权结构与融资历程
四、技术路线与产品
Q&A                                    ← 独立区块，不编号
```

### 各节写什么

**`<公司简称>项目简介`** —— 一段话讲完这家公司是谁。必含：公司全称 + （以下简称"X"）+ 成立时间 + 注册地 + 定位 + 核心团队来源 + 技术渊源 + 融资现状 + 本次交流内容概述。不换行、不分点，200–350 字。

参照写法：

> 北京星阑科技有限公司（以下简称"星阑"或"公司"）成立于 2026 年 4 月，注册地位于北京，定位为全球首家面向太空作业的具身智能公司。核心团队源自北京邮电大学与北京大学，依托"天算星座"及空间机器人技术重点实验室等平台……公司已于 2026 年完成天使轮融资，现启动天使+轮融资，计划融资人民币 8,000 万元至 1 亿元，投后估值约 5 亿元，星途资本担任独家财务顾问。本次交流中，创始人就行业逻辑、技术路线、场景规划、在轨验证计划与融资安排等做了系统性介绍。

**`一、公司概况与定位`** —— 成立情况（时间、注册地、注册资本、股东出资）、公司命名由来、业务定位、主营业务概述、技术原理简述、客户与覆盖范围。素材有多条业务线时在此节下开子节。

**`二、创始团队`** —— **一人一段，逐人介绍**（云驰半导体的做法）。

- 每段以加粗的 `姓名（职务）` 开头（`李明（创始人、CEO/CTO）`），段内写该人的学历、履历、代表成果、专利/论文数量与行业职务
- **顾问与管理层同样逐人成段**——不合并成一段、不串成无主语的履历清单（把「连续创业者」「腾讯投资总监」「BCG 项目经理」并列在一句里而不标明归属，读者无从判断谁是谁）
- 人员分「创始／顾问／管理层」等多组、每组 ≥3 人时**开子节**（见第三节）
- 收尾用 `人才结构特点` 一段收束，写团队跨哪些背景、哪一层集中在什么职能 + 团队完整性判断

素材不支撑逐人写成段时（只给了人数没给履历），照实按人列名并标「（待补）」，**不要为了凑段落编履历**。素材充分时也可拆成 `创始人经历` + `公司团队` 两节（远瞳科技的做法）。

**`三、股权结构与融资历程`** —— 创始股东与一致行动安排、历轮融资（时间、轮次、金额、领投跟投方、投后估值）、现有股权结构、本轮融资安排（金额、估值、释放比例、资金用途）、历史遗留问题。云驰半导体把商业前景测算也并入此节，节名作`融资需求与财务预测`——**含义相同，节名可随内容调整**。

**`四、技术路线与产品`** —— 技术原理、技术路线选择理由、产品体系与形态（分层/分线）、关键指标与竞品对比、技术壁垒来源。技术路线复杂时拆子节。

**`Q&A`** —— 独立区块，**不加中文序号**（样本里卓然/星阑/云驰半导体均不编号，只有远瞳异类编成「四、Q&A部分」）。详见 `qa-spec.md`。

## 二、备选节（按素材具备情况增补，每次必停确认）

命中 1–3/4，**素材支撑才加**；加了要能说出素材出处。

| 备选节 | 样本命中 | 触发条件 |
|---|---|---|
| 行业背景与市场空间 | 2/4 | 素材含行业数据、政策文件、需求测算、行业增长逻辑 |
| 应用场景与商业化路径 | 2/4 | 有阶段性落地规划、目标客户、订单获取渠道、盈利模式 |
| 竞争格局与差异化壁垒 | 1/4 | 有明确对标公司、格局判断、壁垒论述（否则留 Q&A） |
| 生态资源与政策协同 | 2/4 | 有星座/联盟/创新中心/国资平台/兄弟公司等生态 |
| 里程碑与融资计划 | 3/4 | 有明确时间表与资金拆分（常并入「股权结构与融资历程」，不单独开节） |
| 经济性与财务测算 | 2/4 | 有成本结构、售价、毛利率、财务预测 |
| 技术方案详述（子节） | 1/4 | 技术路线复杂到需要拆「（一）（二）（三）」逐个讲 |
| 与传统路线的对比 | 1/4 | 存在明确的技术路线之争（卓然 vs 托卡马克） |
| 研发验证基础与专利安排 | 1/4 | 有实验验证进展、专利归属与切割问题 |
| 业务线拆解（子节） | 1/4 | 公司有多条业务线，需逐条讲（云驰半导体的 WAT / OWAT） |

**默认 4–8 节**。素材只能撑起必备五节时，就只出五节——宁缺毋滥，不要为了凑节数注水。

## 三、子节用法

两种等价写法，都渲染为缩进一级的加粗标题：

- 中文括号序号：`（一）LTD重频大电流驱动器`（卓然）
- 业务线命名：`业务线一：WAT 晶圆允收测试设备（现金牛）`（云驰半导体）

子节标题**自带序号文本**，脚本不做自动编号。

何时开子节：同一节内有 3 段以上、彼此并列、各自有独立名称的内容块。少于 3 块不要开子节，直接分段写。

团队节的常见用法：创始团队节里人员分「创始／顾问／管理层」等多组、**每组 ≥3 人**且各组职能不同时开子节，标题用 `（一）创始团队`、`（二）产业顾问`、`（三）管理团队`。分节后节内段落排在子节**之前**，收尾段（如 `人才结构特点`）用 `outro` 排在子节**之后**（见 `SKILL.md` 的 JSON 结构说明）。

## 四、节标题命名

- 一律**名词短语**，不加「关于」「简述」等
- 长度 6–14 字
- 序号手打：`一、` `二、`……（十以上用`十一、`）
- 节标题**必须由脚本外的手打文本给出**，不依赖 Word 自动编号——云驰半导体原件用的是自动编号，文本流里看不到序号，渲染时换成手打，视觉一致

## 五、骨架确认的呈现格式

第 3 步「骨架确认」时，按下面格式输出，**不要**只扔一个标题列表：

```
【必备节】固定带上的五节
一、公司概况与定位
二、创始团队
三、股权结构与融资历程
四、技术路线与产品
Q&A

【建议增补的备选节】
+ 行业背景与市场空间 —— 素材有 2027 年专项指南、2035 年月球基地等政策与需求数据（出处：素材第 3 段）
+ 应用场景与商业化路径 —— 素材有四阶段落地规划与客户拆解（出处：创始人介绍场景部分）
+ 竞争格局与差异化壁垒 —— 素材有传统航天机器人公司/地面具身公司两类对手的对比论述（出处：Q4 之前）

【不建议增补】
- 经济性与财务测算：素材无成本与毛利口径，只有融资额
- 研发验证基础与专利安排：素材只提到 RROS 在轨两年，撑不起一节

最终骨架 7 节。有要增删的吗？没问题的话说一声「继续」，我就逐节成文。
```
